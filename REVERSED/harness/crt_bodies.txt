# Ghidra decompiled the *runtime's own* functions as ordinary `sub_XXXX` bodies, and those
# cannot run in a rebuild: they use the MSVC 6 FILE layout (0x0C = `_flag`, 0x10 = `_file`)
# and the 2001 CRT's `_iob` table and heap - none of which a modern `fopen` produces.  The
# game's first save write (`sub_41C050`) faults on exactly that: the reversed `fclose`
# writing through a FILE structure the rebuild never made.
#
# The bodies are therefore removed from *both* builds and harness/crt_aliases.c supplies the
# same names as calls into the modern CRT (the same decision already taken for _malloc,
# _strlen and the C++ runtime).  The names are the *call targets* IDA prints - `_fopen`,
# `_fwrite`, `_fclose` - mapped to the Ghidra body that implements them.

sub_562AEE       # _fopen   -> fopen
sub_562B75       # _fwrite  -> fwrite
sub_5628EB       # _fclose  -> fclose
sub_562717       # _sprintf -> vsprintf (via a variadic wrapper)
sub_56279D       # _strtok  -> strtok

# Found the same way, reached now that the game's static initialisers run
# (tools/gen_crt_initialisers.py, called from harness/exe_main.c): every one of the 72
# initialisers ends in `push <destructor>; call sub_5626AD`, i.e. the 2001 CRT's `_onexit`
# registration, and that walks the 2001 CRT's own table (`DAT_006db930`/`DAT_006db92c`) -
# which a rebuild never initialises, because the modern CRT keeps its own.  Measured: the
# access violation is at `_sub_5645F3+0x38` under `_sub_562640+0x11` under
# `_sub_5626AD+0xF` under the first initialiser `sub_402710`.  Dropping the three makes the
# registration a no-op stub; the destructors are a shutdown-only concern.
sub_5626AD       # _onexit  -> the modern CRT registers its own; the 2001 table is not ours
sub_562640       # the __onexit table growth behind it
sub_5645F3       # that growth's remaining-capacity helper

# of these itself:

sub_56C06A       # an internal CRT flag initialiser (DAT_006db928)
sub_567FCA       # installs the game's top-level exception filter; the modern CRT installs its own
